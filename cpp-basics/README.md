# C++ Basics

This folder documents my journey of learning C++ from the fundamentals before moving deeper into Data Structures and Algorithms (DSA).

I'm starting with the basics, focusing on understanding concepts rather than memorising syntax or copying code.

## Learning Goals

- Understand the structure of a C++ program.
- Learn variables and data types.
- Understand input and output using `cin` and `cout`.
- Practise arithmetic and logical operators.
- Learn conditional statements and loops.
- Understand functions and how to use them.
- Build confidence by writing small programs independently.

## My Approach

1. Understand the concept.
2. Write the logic in my own words.
3. Implement it in C++.
4. Test the program with different inputs.
5. Document mistakes and lessons learned.

**Goal:** Build strong programming fundamentals before moving on to DSA problem-solving.
