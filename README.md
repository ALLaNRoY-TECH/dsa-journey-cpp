# DSA Journey in C++

I'm documenting my journey of learning C++ and Data Structures & Algorithms for technical interviews and placement preparation.

## Goals
- Build strong programming fundamentals.
- Understand DSA concepts instead of memorising solutions.
- Solve problems independently and improve problem-solving skills.
- Track my progress and mistakes.

## Learning Roadmap
- [ ] C++ fundamentals
- [ ] Time and space complexity
- [ ] Basic mathematics
- [ ] Arrays and strings
- [ ] Binary search
- [ ] Recursion and backtracking
- [ ] Linked lists, stacks and queues
- [ ] Trees and graphs
- [ ] Dynamic programming

I will add notes, practice programs, and problem solutions as I learn each topic.

## Why I Started This Journey

Being in my third year of college made me realise that my technical skills weren't where I wanted them to be. I felt behind, and at times, I questioned whether I was good enough.

But I realised something: **when you feel like you're falling behind, the best thing you can do is get back up and start building again.**

Instead of worrying about where I should have been, I decided to focus on where I am today and work towards where I want to be.

This repository is my commitment to rebuilding my programming fundamentals from the ground up, learning DSA properly, making mistakes, solving problems independently, and tracking my progress along the way.

I'm not here to pretend I know everything. I'm here to learn, improve consistently, and become a better problem solver, one concept at a time.
